# Tsavorite Toss

Full-colour Python 3 neon gravity-basketball arcade for ElbowOS.

Charge a lime orb and loft it through a sliding tsavorite hoop.
Bank off the court walls. Streaks stack on clean dunks.
A / D aim. Space / W charge then release to toss. R reset.

## Play

```
pip install -r requirements.txt
python3 tsavorite_toss.py --play
```

## Record a 9:16 reel

```
python3 tsavorite_toss.py --record
```
